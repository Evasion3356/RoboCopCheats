# Changelog

All notable user-facing changes to RoboCop Cheats are recorded here. Format
loosely follows [Keep a Changelog](https://keepachangelog.com/). The release
workflow takes each version's notes from its `## [X.Y]` section.

## [1.0] - 2026-11-13

### Added
- Clickable "RoboCop Cheats" menu in the UE4SS window (Ctrl+O).
- 17 weapons, delivered fully loaded like a real pickup.
- Ammo for every weapon type, in any amount (including Rifle and LMG ammo).
- Auto-9 chips: choose connections, the value % the game shows, and a look.
- Auto-9 upgrade boards.
- DLC starting weapon (Deluxe edition): start levels with any weapon instead
  of the OCP Combat Shotgun.
- Hotkeys (F7/F8/F9) and console commands as an alternative to the menu.
